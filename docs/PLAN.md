# 実装計画

1. TypeScript、React、MUI、Express、SQLiteの基盤とDocker Composeを作成。
2. 発行者・振込先設定、連絡先の登録・編集・CSV一括取込を実装。
3. 複数宛先に対する個別請求書発行、検索、状態フィルタ、ページングを実装。
4. PNG書類生成、共有・ダウンロード、Cloudflare SMTP送信を実装。
5. 請求書に紐づく領収書の発行と、送信後の完了処理を実装。
6. 最小限のAPIテスト、型チェック、ビルド、操作確認を実施。

## 設計上の決定

- 単一管理者・日本円（正の整数）・日本時間。複数人を選択した場合、入力金額は一人あたり。
- 金額の自動割勘、税計算、適格請求書、認証利用者の追加は対象外。
- SQLite WALモードでローカル永続化。Docker named volumeに保存。
- 全画面/APIをBasic認証で保護。VPN内利用を前提に、外部公開しない。
- 発行済み請求書は変更せず、宛先・発行者・口座のスナップショットを保持。
- 領収書は一請求書につき一枚。金額は請求額を引き継ぎ改変しない。
- SMTP受付成功で送信済み。配達・既読は保証しない。共有後は利用者の確認で記録。
- メール失敗時に状態を進めない。送信操作を直列化し二重送信を抑止。
- 削除用API・UIは設けず、ファイル削除も事前承認なしに行わない。
