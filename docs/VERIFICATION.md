## nginx HTTPS対応（2026年11月20日）

- `npm test`: 既存API結合テストと追加したプロキシ設定のテストが成功。
  - HTTPSのOriginとHostのポート番号が一致する更新操作を許可し、異なるポートを拒否。
  - `TRUST_PROXY=1`では直前の1段だけを信頼し、認証失敗による制限を接続元IPごとに適用。
  - 直接起動の既定設定では`X-Forwarded-For`による制限回避を拒否。
- `npm run build`: 型チェックと本番ビルド成功。
- Docker・nginx実行環境と利用者の証明書がないため、コンテナ起動・`nginx -t`・実際のTLS接続は未検証。READMEに配置・構文確認・起動・更新の手順を記載。

## 初回検証

2026年11月19日、Node.js 24環境で検証。

## 自動検証

- `npm run build`: TypeScript strictの型チェックとVite本番ビルド成功。
- `npm test`: 最小限のAPI結合テスト成功。
  - 未認証アクセスと別Originからの変更操作を拒否。
  - 不正メール、重複メール、不正日付、小数金額を拒否。
  - CSVの途中に不正行がある場合、全件を未登録のまま維持。
  - BOM付きCSV、引用符付きの値、一覧ページング。
  - 振込先変更後も発行済み書類の口座を保持。
  - 請求書PNGと領収書PNGの生成。
  - メール失敗時は未送信のまま、成功時だけ送信済みへ更新。
  - 未発行領収書の送信、重複発行、確認なしの再送を拒否。
  - 領収書の送信記録で完了、再接続後もDBを保持。
- 依存パッケージ監査: 既知の脆弱性0件（修正版へ更新後）。
